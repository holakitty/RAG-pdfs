Native Android App (Kotlin & Jetpack Compose)

RAG AI Pipeline & Research Assistant

A mobile Retrieval-Augmented Generation (RAG) engine featuring on-device Room SQLite (FTS4), 64-dimensional semantic vector search, Reciprocal Rank Fusion, PDF ingestion up to 20 documents, and clean, paragraph-based Q&A with Gemini API integration.

Why is there an index.html here?

If you pushed this project from Google AI Studio to GitHub and noticed a missing index.html when enabling GitHub Pages: this repository is a native Android mobile application built with Gradle and Kotlin, not a web application!

To run or install this app, you can test it directly in the Google AI Studio emulator, build the APK/AAB file using Android Studio, or install it directly onto any Android phone.

Core Architecture & Capabilities

Hybrid RRF Search Engine

Combines SQLite FTS4 inverted full-text keyword indexing with normalized 64-dimensional vector embeddings via Reciprocal Rank Fusion (k = 60).

PDF Document Ingestion

Supports importing and indexing up to 20 technical and research PDFs with automatic text extraction, sentence chunking, and token analysis.

Asterisk-Free Curated Answers

All Q&A responses are written in clean, authoritative multi-sentence paragraphs completely free of markdown asterisks or bullet clutter.

Offline Local RAG Fallback

Operates autonomously even without an API key by synthesizing retrieved document chunks directly on-device with bracketed citations.

How to Build & Run

Open this repository in Android Studio or run the Gradle commands below:

# Clone the repository
git clone https://github.com/your-username/your-repo.git

# Build the debug APK (installable on any Android phone)
./gradlew assembleDebug

# Output APK path:
# app/build/outputs/apk/debug/app-debug.apk

# Build the release Android App Bundle (for Google Play Console)
./gradlew bundleRelease
